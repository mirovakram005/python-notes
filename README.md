# Python Notes 

## What is Python?
Python is open-source,dynamically typed,interpreted, high-level programming language created by Guido Van Rossum and realeased in 1991.
Now It is one of the most used programming language with large community. It was built to be simple,readable and quick to write. 

## Why do we use Python? 
- Huge Ecosystem
- Easy to learn
- Fast to write 
- Cross Platform
- Great for automation
- Large Community 

## Where do we use Python? 
- Web backend and APIs(Django,Flask,FastAPI)
- Automation and scripting
- Data analysis and visualization(pandas,NumPy)
- AI and Machine Learning
- DevOps and System Administration(The main reason why I am learning Python)
- Cybersecurity tools(scanners,network scripts)

## When should we use Python? 
Best choice for: 
- Quick scripts and automation
- Prototypes and learning projects 
- Working and analyzing Data
- Creating an AI (Most used language in AI field)
Not the best choice for: 
- Creating high performance software 
- Mobile apps (even if it has frameworks and libraries)
- Code that must run in a web browser(use JavaScript instead)
